Python 3.11 以降で `python serve.py` を実行し、[配信PCのWebUI](http://127.0.0.1:52393/) を開きます。実験では参加者ごとに `P1`、`P2` のようなユーザーIDを割り当てます。IDを入力するとその人の機器一覧が開き、「切り替え」で次の参加者に交代できます。パスワードは使わず、同じIDを入力した人は同じデータを開けます。英字の大文字・小文字は区別しません。

「Add」で説明書PDFを選び、機器名と任意の型番を登録します。PDF・表紙・機器情報は配信PCの `.local/users/P1/manuals.sqlite3` のようにID別に保存します。`pdftoppm` が利用できる環境では表紙も生成します。旧版の共有データベース `.local/manuals.sqlite3` はID `LEGACY` で開けます。

一覧の下部の「ユーザーを削除」から対象IDを確認し、「削除する」を押すと、そのIDの保存データを削除します。同じIDを入力し直すと空の一覧で始まります。
