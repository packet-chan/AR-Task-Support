# 実装状況

## 配信PCで使える機能

| 機能 | 動作 | 主な実装 |
| --- | --- | --- |
| 参加者の切り替え | IDごとの一覧を開く。新規IDは空の一覧で始まる。 | [ID入力](../web/index.html)・[user_id](../serve.py) |
| PDF登録 | 「Add」でPDF、機器名、任意の型番を登録する。 | [フォーム](../web/library.html)・[do_POST](../serve.py) |
| 機器一覧 | 表紙・機器名・型番を新着順に表示。タイルから別タブでPDFを開く。 | [manualTile](../web/library.js)・[スタイル](../web/library.css) |
| 参加者の削除 | 対象IDを確認して、その参加者のデータを削除する。 | [確認操作](../web/library.js)・[do_DELETE](../serve.py) |

[ID・PDF・保存先の仕様](機器ライブラリ.md)

タイル左の3段階表示は、現在すべての機器で「PDF取込済み」が点灯する。
