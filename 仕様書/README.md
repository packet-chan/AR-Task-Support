# 実装状況

配信PCのブラウザで、参加者が自分の機器一覧を開き、説明書PDFを登録・閲覧できます。以下はこのWeb版の実装範囲です。

| 機能 | 現在の動作 | 実装場所 |
| --- | --- | --- |
| 参加者の選択・切り替え | IDを入力してその参加者の一覧を開く。初めてのIDには空の一覧を作る。 | [ID入力画面](../web/index.html)、[サーバー](../serve.py) の `user_id` と `Library.do_GET` |
| 説明書の登録 | 一覧右上の「Add」でPDFを選び、機器名と任意の型番を登録する。 | [登録フォーム](../web/library.html)、[送信処理](../web/library.js) の `form.onsubmit`、[保存処理](../serve.py) の `Library.do_POST` |
| 機器一覧・PDF閲覧 | 新しく登録した順に表紙・機器名・型番を表示する。タイルを選ぶと元のPDFが別タブで開く。 | [一覧とタイル](../web/library.js) の `refresh` と `manualTile`、[表示スタイル](../web/library.css) |
| 参加者の削除 | 対象IDを表示し、「削除する」でその参加者の機器情報・PDF・表紙をまとめて削除する。 | [確認画面](../web/library.html)、[削除操作](../web/library.js) の `confirmDelete.onclick`、[削除処理](../serve.py) の `Library.do_DELETE` |

操作条件、保存先、既存データの扱いは[機器ライブラリ仕様](機器ライブラリ.md)にまとめています。
