# 機器ライブラリ

## 参加者を選ぶ

実験では参加者ごとに `P1`、`P2` のようなIDを割り当てる。パスワードはなく、同じIDを入力した人は同じ機器一覧を操作できる。「切り替え」でID入力画面に戻る。

IDは1〜32文字。先頭は半角英数字、2文字目以降は半角英数字・ハイフン・アンダースコアを使える。前後の空白を取り除き、英字を大文字にそろえるため、`p1` と `P1` は同じ参加者になる。Windowsの予約名は使用できない。

## 説明書を登録する

「Add」でPDFを1件選ぶと、ファイル名から拡張子を除いた文字列が機器名の初期値になる。機器名は編集でき、型番は空欄でも登録できる。PDFの上限は128 MiB。

配信PCに `pdftoppm` があれば、PDFの1ページ目から表紙を生成する。表紙を生成できない場合もPDFを保存し、タイルには「PDF」と表示する。

## 保存と削除

既定の保存先は参加者ごとの `.local/users/<ID>/manuals.sqlite3`。機器名・型番・元のPDF・生成した表紙を同じデータベースに保存する。旧版の共有データベース `.local/manuals.sqlite3` はID `LEGACY` から開ける。

一覧下部の「ユーザーを削除」で確認画面が開き、最初は「キャンセル」にフォーカスする。「削除する」を押すと対象のデータベースを削除し、ID入力画面に戻る。同じIDを再入力すると空の一覧で始まる。
