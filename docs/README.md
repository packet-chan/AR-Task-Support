# 実装状況と仕様

| 段階 | 実装・対象 | 詳細 |
| --- | --- | --- |
| S1・S2 | 説明書PDFと選択型番から、原文・注意・図・部品・3Dモデルと動作を生成。PCと端末のブラウザでSTEPごとに再生 | [生成指示](../generation/) |
| S3 | Quest 3で日本語の依頼に沿って写真を撮り、動きの確認には動画を追加。配信PCで保存・再生 | [撮影と音声](capture.md)・[初回利用プロトコル](first-use-protocol.md) |
| S4 | 撮影原本をレビューし、根拠を記録して別版のS2を作成。HD8943には本体の位置合わせと部品別のAR支援を実装 | [改訂の固定手順](s4.md)・[位置合わせ](s4-alignment.md) |

個人端末の追加とDEMOの2分招待は[配信と端末登録](access.md)を参照。

## 生成と保存

「Add」でPDF（128 MiBまで）・機器名を登録し、型番を選ぶ。配信PCはPopplerとCodex CLIを使い、1件ずつ生成する。各段階で形式・参照を検査する。作業支援画面を開くと中断した処理を再開でき、エラー時には再試行できる。

参加者別の登録・進捗は `.local/users/<ID>/manuals.sqlite3`、成果物は同じ参加者の `devices/<世代ID>/<型番>-<取込ID>/` に保存する。

| 保存先 | 内容 |
| --- | --- |
| `S1/task_step.json`、`S1/figure/` | 選択型番の手順・注意事項・出典ページと説明書の図 |
| `S2/bindings.json`、`S2/model.glb` | STEPと部品・動作の対応、実機確認メモ、初版モデル |
| `S3/captures/<撮影ID>/` | 写真・動画の原本と、その撮影を依頼したSTEP・部品・構図 |
| `S4/` | 固定した入力、改訂版、前後の比較、位置合わせ計画と測定記録 |
