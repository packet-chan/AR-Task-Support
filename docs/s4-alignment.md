# S4 実機位置合わせ・AR支援

HD8943の映像レビューで作った改訂版に、位置合わせ用の点と部品確認を追加する。モデルの点は予測であり、Questでの測定と利用者の目視確認を経て、そのセッションのAR表示に使う。過去作の `ContentAlignment.cs`（Horn法）、`ContentLandmarks.cs`（可変点数・独立確認点）、`ContentModel.Adjustments.cs`（部品別の補正）を参照した。

## HD8943で試す

1. 承認済みのQuestで参加者 `LAB6-20261120` のHD8943を開く。最初に試すなら「起動」の4番目のSTEP（電源コード）を選び、「位置合わせ・AR支援」を押す。
2. 扉とふたを閉じた実機で、天板の手前左角、天板の奥右角、底部の手前左角を順に指す。コントローラーは前方8 cmの青い球を合わせてトリガー、手は人差し指を合わせてピンチする。3点目で位置・向き・倍率を求め、本体外形の線を約1秒間だけ実機に重ねる。独立した確認点を取るまでは仮合わせとして扱う。
3. 選んだSTEPの説明と黄緑の輪郭を見比べる。対象の輪郭と印は約8秒表示する。動作があるSTEPでは、その場で既存クリップを再生し、動いている部品の線を明るくする。「次のSTEP」で進み、「STEPを選ぶ」で別の手順に直接移れる。「動作を再生」で見直せる。各STEPで測定を求める画面は出ない。
4. 印がずれていたら「位置を直す」を選ぶ。「写真と点」または「点だけ」を選び、その部品を1回指す。モデルは指す間消える。写真付きなら同じ決定操作でカメラの最新フレームを取り込む。印と写真を見て「重なりを確認」を押す。機器側差込口を調整しても本体はその場に残る。「修正をやめる」で直前の表示へ戻れる。パネル全体にずれがある場合は「その他の操作」→「位置合わせに戻る」→「操作パネルを詳しく」で四隅と画面中央を測る。
5. 図を読むには「図を拡大」を押し、図全体のうち読みたい場所を押すとその範囲が4倍になる。ボタンでも全体・2倍・4倍を切り替えられ、「次の範囲」で隣の領域へ移る。「次の図」があれば別図も読める。最後に「その他の操作」→「記録して終了」を押し、配信PCで「直近の位置合わせ記録」を開く。

位置合わせパネルの初期サイズは通常幅60 cm、図を開くと78 cm。手入力ではそれぞれ44 cm・56 cm。鍵で固定し、持ち手で距離・位置を調節できる。手の表示と操作は[MRパネルの位置](capture.md#mrパネルの位置)を参照。

過去作の `ContentModel.Overlay.cs` の折れ目の抽出と表示時間を参照した。機器を置くときの見本には本体と通常装着されている扉、タンク、抽出口などを含める。HD8943ではカップ・コード・カラフェ・清掃用品など10系統を付属品として指定し、子部品にも適用する。付属品は見本の寸法計算からも外し、実機上には対象として選んだときか、その付属品に登録された動きを再生するときに線を出す。指す間はモデルと記録点を隠し、採用画面で補正後の印を表示する。

操作改訂2では過去作の `ContentWorkspace.Presentation.cs`、`ContentWorkspace.Interaction.cs`、`ContentWorkspace.ModelGrab.cs`、`PlaceModel()` を照合した。見本の中心を開始時の頭から前方1.05 m・右35 cm・下45 cmに置き、向きを保つ。コントローラーのグリップで見本だけを移せる。記録済みの目印は「範囲番号‐点番号」で実空間に残る。右Bまたは「1点戻す」で直前の点を戻せる。球は追跡中のメニュー操作でも表示し、追跡が戻れば実際の先端位置から表示を再開する。

以下は任意の詳細確認で使う点と判定値。

| 範囲 | 合わせる点 | 別に確かめる点 | 今回の採用条件 |
| --- | --- | --- | --- |
| 本体 | 天板の手前左・手前右・奥右、底部の手前左 | 底部の手前右 | 各基準点のずれと確認点のずれが各25 mm以下 |
| 前面パネル | パネル外枠の左上・右上・右下・左下 | 表示画面の中心 | 各基準点10 mm以下、確認点5 mm以下 |
| 必要な部品 | 指示した表面や開口の中心 | 置いた印の目視 | 点を1回置き、利用者が採用。誤差の閾値なし |

これらは指し直しを促すための試行値。実機の位置精度は未評価。差込口は説明書p.3とS4の背面写真から機器側の対象を特定した。写真で得られたのは背面下部という対応までで、開口中心の座標は今回も実機で指す。S2の `Cord` を使うSTEPの空間指示だけを `Socket` に割り当てた。壁側のコンセントには印を出さない。

## 機種共通の固定手順

- [作成指示](../generation/s4-alignment.md)に従って、S1・改訂モデル・S4レビューを照合する。基準姿勢、位置合わせ範囲、実機で識別できる点名、ノード内の位置、許容値、部品の可動性、必要なSTEP例外を指定する。[HD8943の設定](../generation/alignment/HD8943.json)
- 通常は機器に指定した3点で一度だけ粗合わせする。局所を測定するまでは本体と同じ変換を使う。詳細確認を選んだ場合は、装置全体または局所範囲について、一直線に並んでいない3点以上から回転・平行移動・一様倍率を求める。見えない目印は「この点を飛ばす」。別に取った確認点で検査する。目安を超えたときは、超過が最も大きい点の番号・ずれ・目安を表示する。その点だけ取る、番号で別の点を選ぶ、または「仮合わせで続ける」を選べる。変換を計算できない範囲も保留して次へ進める。
- 部品の位置修正では実物と青い球だけを見て1回指す。普段の確認でも「その他の操作」→「実物だけ見る」で仮想モデルと記録点を消せる。
- 暫定モデル上の予測点から実測点への平行移動量を、その範囲のモデル座標で求める。採用すると部品階層に適用する。2回測定した旧記録は従来の誤差付きで表示できる。
- 本体を動かしたときは「位置合わせに戻る」から本体を取り直す。扉を動かしてパネル位置が変わった場合も該当範囲を取り直す。範囲の再登録は依存する確認を無効化する。登録した可動部品はSTEP変更時に再確認する。追跡原点のリセット、新しいMRセッションでは本体から取り直す。
- 「記録して終了」でモデル版、STEP、対象部品、予測点、実測点、使用した座標変換、補正量を配信PCへ送る。写真付きはJPEGと、取得できた場合の頭部姿勢も対応付ける。通信失敗時は同じ写真・記録で再送できる。PCの「直近の位置合わせ記録」で写真を開ける。

## 公開と検査

```powershell
$d = Get-ChildItem .local/users/LAB6-20261120/devices/*/hd8943-*
node tools/s4-alignment.mjs $d.FullName c55920547b04be98 638ba8e80def9145 generation/alignment/HD8943.json
node tests/check-alignment-fit.mjs
python tests/check-alignment-xr.py $d.FullName
```

生成時に改訂S2のハッシュ、全53部品の対応、基準点と確認点、STEP参照を検査する。機器の `S4/alignment-plans/<ID>.json` にモデル座標と版のハッシュを保存し、`S4/alignment.json` で使用版を指定する。ブラウザでもS1、改訂GLB、改訂対応表のハッシュを照合する。実測は `S4/alignment-records/<セッションID>.json` に保存する。撮影レビュー、初版・改訂版のS2とは別の成果物。機種ごとの点指定はHD8943で実装済み。

PC検査は一時参加者とChromeの模擬XR入力で行う。3点で本体の輪郭が現れて消えること、抽出口の輪郭が移動しカップが該当クリップの間だけ現れること、パネル四隅のトリガー操作と手のピンチで対角が動かず伸縮すること、差込口を35 mm補正しても本体位置が動かないこと、部品測定を挟まず次のSTEPでクリップが始まること、別の手順の選択、注釈がない図の4倍表示、パネル詳細確認と配信PCでの保存結果を検査する。装着中の図の可読性と実機の重なり精度は実機での確認項目。
