# 初めて装着する人の撮影とモデル修正

最初の目標は、利用者が実機を操作せずに外から識別できる対象を1枚撮り、配信PCで自分の写真を見つけること。実機を動かした動画は、写真を見ても順序・連動・動く方向が決まらないときに追加する。

## 6機種で見つかった問題

2026年11月21日の研究室データのS1・S2から撮影依頼を集計した。従来の70件は写真51件・動画19件。説明書順に並べると3機種で最初が動画だった。部品メモには特定のSTEPに対応しないものもあり、こうした依頼には手順番号を作らず、部品名と図を使う。下表の数字は依頼数。

| --- | --- | --- | --- |
| C7070 | 8／4 | 外装と上部スキャナー | 給紙段の構成は静止画で確認。伸長部の動きが不明なら本体を一緒に映す。 |
| CD-SE50 | 5／2 | 外から見える本体 | プラグやつまみの向きは写真。後ろの支点がどのように動くかが残ればふたの動画。 |

撮影実績はHD8943の動画4本・写真3枚。他の5機種は依頼の点検まで。HD8943では上ぶたの動画で取り外し順を、回収トレイの動画で扉を開けたまま動かす条件を改訂した。抽出口は指で端点が隠れ、移動距離を決められなかった。背面写真で差込口を識別し、暗いスイッチの印字は保留した。観察ごとの根拠と改訂前後の報告は配信PCの `.local/evaluation/HD8943-S4-v1/report.md` にある。

## 1件の証拠をどう使うか

1. **見つける。** 図と名称を示し、実機は今の状態で撮る。保存した写真はその場で見直す。終了・撮り直し・次の写真・動きの確認を選べる。
2. **位置を直す。** S4位置合わせがある機器では本体を先に合わせる。「位置を直す」→「写真と点」で実物に青い球を1回置く。手でもコントローラーでも同じ操作で、仮想物を含まないカメラ画像を1枚取得する。権限が取れなければ「点だけ」で進める。候補を目視し、採用か撮り直しを選ぶ。
3. **写真を編集根拠にする。** PCの「直近の位置合わせ記録」からJPEGと対応記録を開く。版、STEP、部品、写真、実測点、使用した範囲の変換、補正前後の位置を照合する。複数部品が同じ方向にずれているときは本体の合わせ直しから確認する。単一部品に残ったずれはモデル座標での平行移動候補。写真に写るラベル・形状は識別の根拠にする。頭部姿勢はカメラの校正値ではなく、写真上の正確な画素、実寸、回転軸や奥行きはこの1枚で確定しない。S2への恒久反映はレビュー後に別版で行う。現在は採用時の部品移動と根拠保存までを実装した。
4. **残った動きだけ撮る。** 対象と疑問を一つに絞り、本体の固定部、動く前、動いた後が見える短い動画にする。隠れた端点や根拠のない距離は未確定として残す。
5. **迷ったときはその場で聞く。** 通常案内は日本語で読み上げる。個人端末の「音声で相談」は、「声で質問」で該当手順と質問中の音声をGoogleに送る。「写真と声で質問」を選んだときだけ対象の写真1枚を加える。「回答を聞く」または20秒経過でマイクを閉じる。回答は音声・文字で返し、採用や確認の操作は利用者が行う。

## 初回利用者で確かめる項目

初回試行では、承認済み端末を渡し、観察者は対象名・ボタン位置・撮影方法を口頭で補わない。端末設定で介入が必要なら、その時点と理由を記す。次の人にも同じ開始状態と課題を用意する。

| 課題 | 完了を観察できる条件 | 記録するもの |
| --- | --- | --- |
| 6機種のうち1台で初回撮影 | 正しい部品が識別できる写真を保存し、自分でPC上の結果を開く | 機種、初回か、所要時間、撮り直し、権限での停止、最初の人的介入 |
| HD8943で1部品を修正 | 本体合わせ後に対象を1回指し、補正結果と写真をPCで特定できる | 対象取り違え、表示を隠した場面、採用・保留、補正が本体か部品か |
| 判断に迷った場面で相談 | 自分で質問し、回答から次の一手を選べる | 質問、画像の有無、回答が挙げた特徴、人手照合での誤答・断定、再質問 |
| モデル編集の再利用 | 別の人が記録から同じ対象・修正方向・未確定点を説明できる | 採用根拠、追加写真・動画の理由、実機と独立に照合した結果 |

各参加者の最初の1台を「初回」として集計し、残りを同じ人が試した場合は習熟後として分ける。写真の保存、修正の成功、第三者が実際に使えるモデルの完成は別々に記録する。人による助言、Geminiによる助言、完全に自力だった範囲も分ける。現時点で初回利用者の達成率は未測定。

## 配信PCで確認した範囲

通常URLで6機種とも最初の依頼が写真になったことを確認した。CD-SE50とPRO-6600は模擬Questで、カメラ権限エラーからの復帰、写真の保存・見直し、任意の動画への切替とPC再生まで確認した。HD8943では差込口を1回指して模擬写真と35 mmの補正を保存し、表示画面は点だけで保存した。Gemini Liveの実接続には青い四角の合成画像と色を尋ねる合成音声を使い、「その正方形は青色です」という日本語の回答と音声出力を確認した。[Googleの入出力仕様](https://ai.google.dev/gemini-api/docs/live-guide)
