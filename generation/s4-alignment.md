# S4 alignment authoring prompt, version 3

Use the verified S4 revision and its original S1 manual. Design the registration and pointing plan for this specific machine. Keep its S2 model, bindings, instruction text and animation clips intact.

1. Inspect the reference pose, model hierarchy, S1 figures and S4 evidence. Name the physical state and the exact feature to point at in Japanese. Treat every authored coordinate as a model hypothesis, including positions that look plausible in a photograph.
2. Start with widely separated, unambiguous fixed housing features. Add local groups when several targets share an assembly, for example the four corners of the control panel. For each similarity fit choose at least three non-collinear points and a distinct recognizable check feature excluded from the fit. Use as many landmarks as the physical features justify. Record the fit and check tolerances in metres.
3. Cover each S2 part with a named, identifiable feature. Bind its model node, feature and group. For an ambiguous STEP, specify the actual pointing target and scope it explicitly (e.g. appliance-side socket versus cord and wall outlet). Flag movable items for rechecking. Record source references and provisional choices in the accompanying protocol. If the target cannot be identified on this unit, instruct the wearer to defer it.
4. Resolve authored positions in the revised glTF root coordinate system and bind the result to the exact model, bindings, and S1 hashes. Publish the plan separately. Actual measurements come from the wearer. A model hypothesis, a fitted correspondence, or a photograph alone cannot mark a part as physically verified.
5. Link each landmark to a manual figure. Mark the corresponding location in the image only when the feature is visible. Keep a stable reference model and numbered physical samples. Support undo, skipping individual points and replacing the largest-error sample.
6. Select three widely separated non-collinear housing landmarks as quickFit indices. After the third point show the full device at the fitted pose and scale. Start the selected STEP immediately with its highlighted target and existing clip sequence. Allow free STEP navigation. Keep unmeasured positions provisional.
7. Offer the detailed group fit and independent check, or single pointing and visual approval for a particular part, only when requested. Without a local fit use the housing fit as the provisional basis. Preserve actual measurements, their basis, and verification status separately from STEP navigation.
8. Identify accessoryRoots by part ID and model hierarchy. Include free-standing vessels, external cables and service supplies. Keep installed machine assemblies in the reference even if they open or can be removed. Omit accessories from registration and expose them temporarily only when the selected target or the currently playing clip specifically refers to them. Keep the source model intact.


9. For a local position correction hide the overlay while pointing. One trigger or pinch records the point and optionally the current outward-camera frame. Ask for visual acceptance. Bind approved evidence to the revision, STEP, part and alignment basis. Use it to review a local translation. A single photograph and an uncalibrated head pose cannot establish dimensions, exact image pixels or a motion path.
