# S4 revision protocol v1

Revise the supplied S2 model and bindings for the selected device using the answers collected in S3. Deliver a complete bindings.json and model.glb that satisfy the existing S2 contract and can be opened by the existing viewer.

Start from the frozen S2 revision. Use the PDF, S1 steps, precautions and figures to establish the intended operation. For each selected S3 capture, read the original request, inspect the actual image or video, and identify which part, step and property the capture provides evidence about. A capture request states a question. Its wording does not establish what happened.

For each property, record the baseline, observation, and one decision: confirmed, revise, or unresolved. Cite the capture ID and video time interval in seconds or image region in normalized top-left coordinates. Cite the manual page or figure when it contributes to the decision. Separate attachment, direction, sequence, travel distance and dimensions. Use measured values only with an identifiable scale. Identify schematic animation offsets, timing and material values explicitly as display choices. If sources conflict, check the device variant, part and operating state. Limit a unit-specific observation to that unit. Leave unexplained differences unresolved.

Apply supported revisions to the smallest affected portion of the baseline. Preserve identifiers and unrelated behavior. Keep all S1 steps, original-language part names, valid figure references and intended clip order. Review each answered note. Retain only outstanding questions in short English S3 notes, anchored to a part or step. Preserve questions outside the run. Keep the original question and evidence in the review log even when a note is retired.

Review before editing. Tie each edit to a decision and include the exact edit parameters. Validate both complete outputs. Replay affected steps and other steps sharing edited parts or clips under the same camera and playback conditions. Record what was verified, unresolved properties, input and output hashes, prompt and tool versions, and the reviewer. Publish an independent candidate revision; keep the baseline and captures intact.
